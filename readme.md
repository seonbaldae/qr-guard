# QR Guard

QR에 담긴 주소를 바로 열지 않고 먼저 검사하는 서비스의 프런트엔드입니다. **QR 촬영 → 검사 중 → 결과 확인**의 세 화면을 HTML, CSS, 순수 JavaScript ES Modules와 open Shadow DOM으로 구현했습니다. 설치나 빌드는 필요하지 않습니다.

화면은 모바일 한 열 구조입니다. 상단 헤더·단계 표시·서비스 소개를 생략하고 흰색·파란색·회색과 큰 버튼으로 촬영과 결과에 집중합니다. 주소 직접 입력과 샘플 체험은 촬영 화면에서 펼쳐 사용할 수 있습니다.

## 로컬 실행

저장소 루트에서 실행합니다.

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

[로컬 화면](http://127.0.0.1:8080/)을 엽니다. QR 촬영은 브라우저의 기본 `BarcodeDetector`가 `qr_code`를 지원해야 합니다. 미지원 환경에서는 URL 직접 입력을 이용할 수 있습니다. 휴대전화 카메라는 HTTPS 환경이 필요합니다.

## 화면 체험과 API 연결

- **실제 검사 모드:** 읽은 URL을 설정된 우리 검사 API에만 전달합니다. 정상 완료 결과에만 사이트 진입 버튼을 제공합니다. 피싱 결과에는 신고 건수와 신고·재스캔 버튼을 제공합니다.
- **데모 체험:** 촬영 화면 아래에서 정상·피싱 샘플을 선택합니다. 사칭 의심, 확인 불가, 검사 오류, 미리보기 없음, 신고 실패도 체험할 수 있습니다. 모든 데모 화면에 실제 검사가 아니라는 안내를 표시하며 실제 사이트 이동은 비활성화합니다.

현재 저장소에는 HTTP 검사·신고 서버가 없습니다. 정적 서버에서 직접 주소를 검사하면 API 연결 오류가 표시됩니다. 기존 Python 정적 분석 모듈이 최종 판정·스크린샷·신고 API를 제공한다고 가정하지 않습니다.

연동 설정은 `src/config.js`, 응답 변환은 `src/services/response-adapter.js`에 있습니다. 직접 응답 또는 작업 생성·폴링 방식을 지원합니다. 제안 요청·응답 계약과 연동 방법은 [프런트 API 안내](docs/frontend-api.md)를 참고하세요.

## 검증

정적 서버에서 다음 페이지를 열면 외부 의존성 없이 검증을 실행합니다.

- [서비스 계층 검증](http://127.0.0.1:8080/tests/frontend/services.html): URL·응답 검증, API 오류·취소·제한 시간, 이미지 출처와 신고 처리.
- [화면 통합 검증](http://127.0.0.1:8080/tests/frontend/ui.html): 실제 Shadow DOM의 폼·버튼, 정상·피싱 분기, 신고 성공·실패, 이전 응답 무시, 재스캔 초기화. API와 새 창은 테스트 대역으로 처리합니다.

모의 검증 통과는 실제 카메라 QR 촬영, 백엔드·격리 환경, 신고 접수 검증을 뜻하지 않습니다. 위협 미탐지도 완전한 안전이나 공식 사이트 인증을 뜻하지 않습니다.

프런트엔드는 카메라 영상·검사 데이터를 저장하지 않습니다. QR 목적지는 정상 결과의 명시적 진입 클릭 전까지 열지 않습니다. Shadow DOM 내부를 검사하려면 `shadowRoot` 순회 또는 이를 지원하는 도구를 사용하세요.
